# obs-music

Плеер для OBS: заказ музыки за баллы канала Twitch по ссылке YouTube, фоном играет плейлист YouTube Music.

- Плеер (источник «Браузер» в OBS): `https://ilen1n.github.io/obs-music/#obs`
- Настройки (док-панель OBS): `https://ilen1n.github.io/obs-music/`

## Панель

Вверху страницы настроек: что играет сейчас, очередь заказов (🔒 — заказ стримера) и последние 3 трека.

## Правила скипа

- Трек, заказанный стримером, может скипнуть только стример (наградой и командой). Модераторская `!очистить` его заказы не удаляет.
- Неудачный скип (ничего не играет, трек стримера, трек уже скипнули) возвращает баллы.
- Команды модераторов работают и для старших модераторов (значок `lead_moderator`).

## Лог музыки для монтажа

Плеер ведёт журнал: что играло и с какой секунды трека, по часам компьютера. Выгрузка: ⚙ в источнике OBS → «Лог музыки для монтажа» → «Скопировать лог» / «Скачать файл». Формат — JSON Lines, одна строка = одно событие:

- `t` — локальное время ПК с часовым поясом (`2026-11-08T21:03:12.345+05:30`)
- `ev` — `play` (трек начал звучать, с полями `url`, `title`, `author`, `dur`, `src` = `bg`/`order`/`urgent`, `by` — кто заказал, `pl` — фоновый плейлист), `pause`, `resume`, `sync` (после подвисания), `end` (доиграл), `stop` (оборван: скип, смена плейлиста), `session` (плеер перезапущен — прошлый трек уже не звучит), `vol` (громкость), `error` (трек не заиграл, `reason` — код ошибки YouTube или `timeout`/`early`)
- `pos` — секунда трека в момент события

Чтобы узнать, что звучало в момент X: найти последнее событие этого трека до X; если это `play`/`resume`/`sync`, то позиция в треке = `pos + (X − t)`.
